# 캐릭터 이미지 (뿌까)

진행 캐릭터 뿌까의 이미지를 이 폴더에 넣습니다.

## 파일 안내
- `pucca_main.png` — 기본/대표 이미지 (홈, 결과 화면 등에서 사용)
- 필요 시 표정·포즈 변형 추가 (예: `pucca_happy.png`, `pucca_thinking.png`, `pucca_wink.png`)

## 사용 위치
- 홈 화면 인사
- 카드 뽑기·로딩 연출
- 결과 화면 해석 옆
- 후속 대화(챗봇) 프로필

> 뿌까 이미지는 부즈(VOOZ) IP이므로 라이선스 범위 내에서 사용하세요.
> 받은 뿌까 얼굴 이미지를 `pucca_main.png`로 이 폴더에 저장하면 됩니다.
