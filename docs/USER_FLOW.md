# User Flow — 뿌까 오라클

| 항목 | 내용 |
|---|---|
| 문서 종류 | 화면 이동 순서 (User Flow) |
| 버전 | v0.3 |
| 작성일 | 2026-07-10 |
| 기준 문서 | docs/PRD.md |

> PRD의 MVP 기능(오늘의 타로 / 클래식 타로 / 타로 카드 도감 / 후속 대화)을 화면 흐름으로 정리한 문서. 참고 서비스(LEO Tarot)의 실제 화면 구조를 기준으로 작성됨.

---

## 0. 전체 흐름 한눈에 보기

```
[홈]
 ├─▶ 오늘의 타로(1장)  ─▶ [질문 선택/입력] ─▶ [카드 뽑기: 스와이프, 1장] ─▶ [결과] ─▶ [뿌까와 대화]
 ├─▶ 클래식 타로(3장)  ─▶ [질문 선택/입력] ─▶ [카드 뽑기: 스와이프, 3장] ─▶ [결과] ─▶ [뿌까와 대화]
 └─▶ 타로 카드 도감    ─▶ [슈트 탭 + 카드 그리드] ─▶ [카드 상세]
```

- **두 리딩 모두 "질문 선택 → 카드 뽑기 → 결과 → 대화" 구조를 공유한다.** (별도의 '질문 타로' 메뉴는 없음)
- 차이는 뽑는 장수뿐: 오늘의 타로 1장, 클래식 타로 3장.

---

## 1. 홈 화면

**목적**: 서비스 첫인상과 리딩 진입점 제공.

**구성 요소** (참고 서비스와 동일한 카드 메뉴 스택)
- 세로로 쌓인 큰 라운드 메뉴 카드 3개:
  1. `오늘의 타로` — "오늘의 운세를 카드 1장으로 간편하게 점쳐줄게"
  2. `클래식 타로` — "카드 3장으로 구체적으로 운명을 점쳐줄게"
  3. `타로 카드 도감` — 78장 전체 카드 열람
- 각 메뉴 카드: 왼쪽 위 금색 세리프 영문 뱃지(Today's Tarot / Classic Tarot / Tarot Card List) + 중앙 뿌까 일러스트 + 하단 한글 제목·설명.

---

## 2. 질문 선택 화면 (오늘의 타로·클래식 타로 공통 1단계)

**구성 (위→아래)**

1. **상단 히어로**: 왼쪽 뿌까 캐릭터 + 오른쪽 안내 문구 2줄 ("요즘 어떤 고민이 있어? 골라봐!"). 보라 신비주의 배경.
2. **질문 입력창**: 라운드 큰 흰색 필드, 플레이스홀더 "고민을 선택하거나 직접 입력해봐!". 직접 입력 가능, 아래 목록에서 선택하면 자동으로 채워짐.
3. **카테고리 탭**: 가로 스크롤 탭바, 이모지+이름 8개 (💘 연애·사랑 / 💼 직장·진로 / 💳 금전·재물 / 🥑 뷰티·관리 / 🧶 인간관계 / 🧸 취미·덕질 / 🎓 학업·시험 / 🎉 기념일). 선택 탭은 흰색+밑줄 강조. 데이터: `data/question_categories.json`.
4. **질문 리스트**: 선택된 카테고리의 질문을 세로 스택으로. 어두운 보라 라운드 버튼, "이모지 + 질문" 좌측 정렬.

**이동**
- 질문 확정(선택 또는 입력) → 카드 뽑기 화면.

---

## 3. 카드 뽑기 화면 (스와이프 선택)

**구성 (위→아래)**

1. **상단 히어로**: 뿌까 + 안내 문구.
   - 클래식: "고민을 생각하면서 카드 3장을 뽑아봐!"
   - 오늘의 타로: "고민을 생각하면서 카드 1장을 뽑아봐!"
2. **선택 슬롯**: 뽑을 장수만큼 카드 프레임 슬롯.
   - 클래식 타로: 3개 나란히, 미선택 시 프레임 안에 금색 "미선택" 텍스트.
   - 오늘의 타로: 중앙 1개.
   - 카드 선택 시 슬롯이 순서대로 채워짐(뒷면 유지).
3. **하단 카드 덱**: 카드 뒷면들이 가로 부채꼴/아치형으로 펼쳐짐.
   - **좌우 스와이프(드래그)**로 덱을 넘기고, 중앙 카드는 살짝 떠오르며 강조.
   - 중앙 카드 탭 → 위 슬롯으로 날아가는 선택 애니메이션.
   - 안내 문구: "카드를 좌우로 이동해 보세요".
   - 터치 스와이프 + 마우스 드래그 모두 지원.

**이동**
- 필요한 장수 선택 완료 → 결과 화면 (슬롯 카드가 순서대로 뒤집히는 공개 연출).

---

## 4. 결과 화면

- 상단에 선택한 질문 표시. 질문 맥락에 맞춘 뿌까의 개인화 해석(반말).
- **오늘의 타로**: 카드 1장 + 한 줄 운세(`reading_sentence`) + 뿌까 해석 + 오늘의 조언. 같은 날 재접속 시 같은 카드 유지.
- **클래식 타로**: 3장 카드 + 포지션별 해석(① 현재 상황 / ② 필요한 조언 / ③ 결과·전망) + 종합 해석 + 실천 조언.
- 버튼: `뿌까랑 더 얘기하기`(후속 대화 진입) + **홈 버튼 1개** (뒤로가기 없음).

---

## 5. 타로 카드 도감

- 상단 슈트 탭: 🌟 Major Arcana / 🪄 Wands / 🍷 Cups / 🗡️ Swords / 🪙 Pentacles.
- 탭별 카드 그리드 → 카드 탭 시 상세(이름·의미·1줄 리딩·키워드 태그).
- 데이터: `data/tarot_cards.json`.

---

## 6. 뿌까와 대화 (후속 챗봇)

**목적**: 리딩 결과에 대해 이어서 대화하며 궁금증 해소.

**구성**
- 상단에 방금 리딩한 질문·카드 요약 고정.
- 채팅 UI (뿌까 = 상대, 사용자 = 나).
- 뿌까는 방금 뽑은 카드·해석 맥락을 기억한 채 반말로 답한다.

**이동/종료**
- `홈으로` 또는 `새 리딩 하기` 버튼으로 흐름 종료.

**상태 유지**
- 대화 세션 동안 질문·카드 맥락 유지 (PRD의 세션 관리 활용).

---

## 7. 네비게이션 규칙

화면별 이동 버튼 정리:

| 화면 | 이동 버튼 |
|---|---|
| 홈 | 없음 (메뉴 카드가 진입점) |
| 질문 선택 | **없음** (뒤로가기·홈 모두 없음, 몰입 유지) |
| 카드 뽑기 | **없음** (뒤로가기·홈 모두 없음, 몰입 유지) |
| 타로 결과 | **홈 버튼 1개만** (+ 기능 버튼 "뿌까랑 더 얘기하기") |
| 뿌까와 대화 | 홈으로 / 새 리딩 버튼 |
| 타로 카드 도감 (목록·상세) | 좌측 상단 **뒤로가기 아이콘만** — 원형 배경 없이 꺾쇠(`<`, chevron-left) 모양만, 텍스트 라벨 없음 |

- 브라우저 물리 뒤로가기로 돌아와도 앱 상태가 깨지지 않게 안전 처리.

---

## 8. 예외·엣지 케이스

- **LLM 응답 지연**: 결과 생성 중 뿌까 로딩 연출("카드를 읽는 중...")로 체감 대기 완화.
- **응답 실패/네트워크 오류**: "잠깐 별이 흐려졌어, 다시 해볼래?" 재시도 안내.
- **부적절/위험 입력**: 직접 입력 질문에서 위기 신호(자해 등) 감지 시, 점술 대신 도움 자원을 안내하는 분기.
- **새로고침**: 결과 화면 새로고침 시 같은 결과 유지(세션/저장 정책에 따름).
- **URL 파라미터**: `?uuid=` 쿼리로 사용자 구분(없으면 익명 처리).
